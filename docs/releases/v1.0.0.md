# PSH Examination Checker v1.0.0

Download **PSH-ExamCR-Setup.exe** from the release assets and run it to install for your Windows account. Python is bundled and does not need to be installed separately. Close any running copy of the application before installing an update.

This release includes:

- Automatic Examinee ID detection when importing an Excel or CSV examinee list.
- Names and imported details in the results page, with highlighted examinees who have no processed scan.
- An **Export results to Excel** button for a PSH score report with examinee names, percentage scores and points.
- Input templates and instructions available from **Templates**.
- Updated documentation and repository organization, with populated examinee datasets removed from the current source files.

The installer is for 64-bit Windows and is not digitally signed. `SHA256SUMS.txt` contains the installer checksum. The source-code ZIP and TAR files are for developers; staff should download the EXE asset.

Validation: all 16 regression tests pass; installer compilation and packaged application startup are checked before publication.
